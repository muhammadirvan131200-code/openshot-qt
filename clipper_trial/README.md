# 60s Learning Clipper Trial

A vertical 60-second proof-of-concept brief for an educational/self-development clipper workflow.

## Trial output
- Format: MP4, H.264 + AAC
- Frame: 720x1280 (9:16)
- Frame rate: 24 fps
- Duration: 00:01:00
- Working title: **Jangan Cuma Nonton. Upgrade Diri Lu.**
- Editorial idea: use a speaker's point as the story spine, then cut away to relevant illustrative footage (e.g. when the speaker says "belajar", show a person actively studying or practicing).

## Important media note
This first render is a **visual proof-of-concept**. It uses original graphic/illustrative scenes, original Indonesian voiceover and original synthesized music. It does **not** contain downloaded source footage from Timothy Ronald, Raymond Chin, or other creators. The in-video note labels the visuals as reconstruction, not original creator footage.

For a publishable creator-based clip, import source files that you have permission to use, select the exact source in/out points, preserve context, and replace illustrative scenes with licensed/authorized B-roll. Do not imply that illustrative B-roll is footage of the named speaker.

## Editing workflow
1. Import approved source clips, illustrative B-roll, voiceover, music and subtitle file.
2. Build the 60-second narrative using the timing in `manifest.json`.
3. Use the speaker's audio as the A-roll only where the sentence is actually present in the source.
4. Add related B-roll over the relevant words (study, coding, creating, reviewing), keeping speaker audio continuous where useful.
5. Use hard cuts and short J-cuts/L-cuts; avoid random stock footage.
6. Burn in readable Indonesian captions and verify that they do not cover faces or important actions.
7. Check music under speech, peak levels, spelling, safe margins and 9:16 framing.
8. Export H.264 MP4 at 720x1280 or 1080x1920, 24/30 fps, with AAC audio.

## Files in this trial
- `manifest.json`: timeline plan and export metadata.
- `sources.md`: candidate source videos and verification notes.
- `voiceover_script.txt`: original VO script for the prototype.
- `captions_id.srt`: Indonesian subtitle file.

The rendered MP4 and source media bundle are delivered separately from this repository branch.
